# Security Policy

We take security vulnerabilities seriously. Thank you for helping keep `resumesh-llm` secure.

## Supported Versions

Only the latest major version is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities via public GitHub issues. Instead, report security issues by following these steps:

1. Send an email to **security@resumesh.dev** containing details of the vulnerability.
2. Include the following details in your report to help us understand and resolve the issue quickly:
   - A descriptive title.
   - The version of `resumesh-llm` affected.
   - A proof of concept (PoC) or step-by-step instructions to reproduce the issue.
   - Any potential impact details.

We will acknowledge receipt of your report within **48 hours** and provide a status update including proposed next steps and estimated time to resolution.

## Resolution Process

1. We will triage and verify the vulnerability in a private environment.
2. If confirmed, we will draft a fix and test it.
3. We will release a security patch under a new version (e.g. `0.1.1`) and update this document if necessary.
4. Credit will be given to the reporter in the release notes unless requested otherwise.
